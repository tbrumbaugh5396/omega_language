## 1. What this is

A website built on an **existing template**, configured and styled for the
Client, populated with content the Client supplies, and delivered in **five
working days**.

This tier exists because it is tightly bounded. Its speed and price depend
entirely on that; the constraints below are the product, not fine print.

## 2. Scope

**Included**
- Up to **[5] pages** from the agreed template
- Colour, typography and logo applied to the template's existing design system
- Client's text and images placed
- Mobile, tablet and desktop layouts as the template provides
- Contact form to one email address
- Basic SEO: page titles, meta descriptions, sitemap
- Analytics installed
- Domain connected and SSL
- One 45-minute recorded training session
- **[14] days** of post-launch defect support

**Not included** — available as add-ons or a higher tier
- Custom design, custom layouts, or changes to the template's structure
- Copywriting, photography, illustration, logo or brand work
- E-commerce, booking, memberships, calculators
- Integrations beyond the contact form
- Content migration from an existing site
- Multi-language
- Ongoing maintenance (see the care plan)

## 3. The one-week condition

The five-day delivery **begins when the Studio has all of the following**, not
when the deposit is paid:

- [ ] Final text for every page
- [ ] All images, sized and rights-cleared
- [ ] Logo in vector format
- [ ] Domain and hosting access
- [ ] Template selected and approved

**Nothing starts until this is complete.** If materials arrive incomplete, the
project is scheduled into the next available week rather than started
partially — a half-fed week website is what turns a five-day job into a
five-week one.

Materials outstanding **[14] days** after signature: the project is
rescheduled and a **$[X]** fee applies.

## 4. Revisions

**One round of feedback is included.**

- Presented once, complete. The Client returns one consolidated set of
  feedback on the supplied form within **[3] working days**.
- The round covers text corrections, image swaps, colour and spacing
  adjustments within the template's existing capability.
- It does not cover layout restructuring, new pages, or design changes the
  template doesn't support — those are a change order or a higher tier.
- Additional rounds: **$[X]** each.
- No response within [5] working days = approval, and the site launches.

> At this price, one round is what makes the maths work. Clients who want to
> iterate should be on the Partially Custom tier, and it's kinder to say so
> before starting than after.
