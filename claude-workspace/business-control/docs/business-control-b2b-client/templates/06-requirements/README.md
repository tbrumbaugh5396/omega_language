# Stage 06 — Agreeing what you're building
| Document | Goes to | When |
|---|---|---|
| `requirements-template.md` | **Client** | Written by you from the brief and questionnaires |
| `requirements-feedback-form.md` | **Client** | With the requirements, for sign-off |

This is the document you point at for the rest of the project. Without it,
"that's not what I asked for" has no answer and you will build it twice.

**Gate:** signed requirements. Design does not start before this — not "we'll
start while they read it". Anything added after this signature is a change
order, and saying so warmly every time is what keeps the margin.
