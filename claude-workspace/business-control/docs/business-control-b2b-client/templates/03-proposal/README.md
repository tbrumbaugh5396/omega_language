# Stage 03 — Pricing it and sending it
| Document | Goes to | When |
|---|---|---|
| `rate-card.md` | Internal — never send | How you build the three options |
| `proposal-template.md` | **Client** | Within 3 working days of the call |
| `sales-deck.html` | **Client** | The screen-share version, if they want a walkthrough |

Always three options, middle one recommended. They get a proposal, not a menu —
the rate card stays internal because a price list invites line-item haggling
over work you already priced as a whole.

**Valid 14 days.** Put the date on it. An open-ended price is an invitation to
come back in six months expecting the same number.

**Gate:** they pick an option in writing. "Sounds good" on a call is not a
choice; ask which letter.
