# Brand exploration

Blank masters: [`templates/07-brand-exploration/`](../../../templates/07-brand-exploration/) —
that folder's README says what gets sent and what opens the next gate.

- `to-client/` — the directions you showed, and the signed art direction.
- `internal/` — the exploration brief, and anything you decided not to show.

The signed [art direction](../../../templates/07-brand-exploration/art-direction.md)
is the reference for everything built afterwards.
Keep it here and keep it findable: in month four, "we never agreed to that" is
settled by this file or by nobody.
