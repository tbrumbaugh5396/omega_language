# Proposal

Blank masters: [`templates/03-proposal/`](../../../templates/03-proposal/) — that folder's
README says what gets sent and what opens the next gate.

## What lands here

| `to-client/` | `internal/` |
|---|---|
| The proposal as sent, dated | Your estimate and the implied-rate check |
| The deck, if you walked them through it | Which option you expected them to take |
| Their written acceptance — **which letter** | |

**The one that matters:** their acceptance in writing, naming the option.
"Sounds good" on a call is not a choice.

> The rate card never lands here. It never lands in a client folder at all.

**`internal/` is never sent.** If it would be awkward to forward, it belongs
there.
