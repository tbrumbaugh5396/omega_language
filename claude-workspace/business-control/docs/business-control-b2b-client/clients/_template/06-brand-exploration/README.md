# Brand exploration

*Optional — run it when the look is the point. Skip it for a week website.*

Blank masters: [`templates/07-brand-exploration/`](../../../templates/07-brand-exploration/) — that folder's
README says what gets sent and what opens the next gate.

## What lands here

| `to-client/` | `internal/` |
|---|---|
| The directions, as presented | Exploration brief — fixed vs open, non-negotiables |
| Their returned choice form | Directions you made and chose not to show |
| **The signed art direction** | Type licences, and what they cover |

**The one that matters:** the signed
[art direction](../../../templates/07-brand-exploration/art-direction.md). It is
the reference for everything built afterwards — in month four, "we never agreed
to that" is settled by this file or by nobody.

> Keep the type licences here too. "Which face was that, and are we allowed to
> put it on the packaging?" is a question that arrives long after everyone has
> forgotten, and the answer is expensive when it's no.

**`internal/` is never sent.** If it would be awkward to forward, it belongs
there.
