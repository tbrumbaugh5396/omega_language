# Requirements

Blank masters: [`templates/06-requirements/`](../../../templates/06-requirements/) — that folder's
README says what gets sent and what opens the next gate.

## What lands here

| `to-client/` | `internal/` |
|---|---|
| The requirements document | Anything you decided to leave out, and why |
| Their **signed** sign-off form | |

**The one that matters:** the signed requirements. It is the thing you point at
for the rest of the project, and everything after it that isn't in it is a
change order.

**`internal/` is never sent.** If it would be awkward to forward, it belongs
there.
