# Launch

Blank masters: [`templates/09-launch/`](../../../templates/09-launch/) — that folder's
README says what gets sent and what opens the next gate.

## What lands here

| `to-client/` | `internal/` |
|---|---|
| Written approval to launch, from the approver | Completed launch checklist |
| The final invoice and its receipt | Pre-launch backup, and proof you restored it |
| Launch summary — what changed, what to watch | DNS zone as it was, screenshotted whole |
| | Redirect map |

**The one that matters:** the pre-launch backup you actually restored. You'll
need it roughly once every twenty projects, and on that day it is the
difference between an inconvenience and a catastrophe.

> Final payment before launch, never after. Leverage disappears the moment the
> site is live.

**`internal/` is never sent.** If it would be awkward to forward, it belongs
there.
