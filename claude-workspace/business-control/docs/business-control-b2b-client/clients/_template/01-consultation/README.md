## What lands here

| `to-client/` | `internal/` |
|---|---|
| Packages & process, as sent | Completed consultation questionnaire |
| The written stack map, if you ran the free consultation | **Discovery brief** — never send |
| | Your notes, and the gut call |

**The one that matters:** the discovery brief. If you can't write its one-liner,
you don't understand the project well enough to price it.

> The stack map was promised within 24 hours. File a copy here when you send it
> — in three months "did we actually send that?" has one answer, and it's this
> folder.

**`internal/` is never sent.** If it would be awkward to forward, it belongs
there.
