# Kickoff

Blank masters: [`templates/05-kickoff/`](../../../templates/05-kickoff/) — that folder's
README says what gets sent and what opens the next gate.

## What lands here

| `to-client/` | `internal/` |
|---|---|
| Welcome guide | Chase log — what you asked for, when |
| The four questionnaires, returned | |
| **`project-roadmap.md`** — lives here for the whole project | |
| The content deadline, in writing | |

**`to-client/project-roadmap.md` is the one document you update and re-send
weekly.** Keep it in place and edit it rather than making a dated copy each
time, so there is always exactly one current answer to "where are we?".

> The content deadline agreed in writing on day one is what makes a slip a
> shared fact rather than an argument. File the email, not just the date.

**`internal/` is never sent.** If it would be awkward to forward, it belongs
there.
