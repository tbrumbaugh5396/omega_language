Price bands three numbers instead of nineteen

The 10+ tier is left at the documented 25%, which inverts: past nine boxes another capability lowers the bill. Set it to 20% and the ladder climbs all the way. Changing it is a pricing decision, so the bench won't make it for you.

Packaged tiers the upgrade, not the escape hatch

A tier is only offered when it covers every selected capability. Starter carries Selling, Payments, Workforce and Comms; Pro adds Inventory, Warehouse, CRM, Marketing and Subscriptions; Scale adds Distribution, Production, Sourcing, Events, Affiliates, Intelligence, Automation and API. Learning, Fundraising and the Finance stack sit outside all three, so those clients buy boxes — which is the honest answer, not a gap.

Scale metric optional — off unless you switch it on

Off by default and it stays off — nothing else in the bench depends on it. When it's on, the band is added to the subtotal, so nonprofit and annual discounts apply to it like any other software line. Active subscribers is the natural metric because the bill run already counts contracts; orders or GMV bands work the same way if you'd rather.

Your plan is sized to how much you're running through it. Growth inside a band costs nothing extra — you only move when you cross into the next one, and you'll see it coming.

Included with every install no extra charge, no extra build

Installable app — all three surfacesPWA

  • Customers add the shop to their home screen and open it like an app — no App Store, no download, no review queue
  • Staff do the same with the ops app; it keeps working through a dropped signal and syncs when the connection returns
  • Push notifications to phones and desktops — order alerts, low stock, incidents — with no per-message fee
  • Camera access for QR and barcode scanning: shelf labels, truck check-in, promo codes, event tickets
  • Microphone access for voice notes and calls, and one-tap sign-in from a QR code
  • One codebase, one deployment — iOS, Android and desktop from the same install

This is why HTTPS on a real domain matters. Camera, microphone, push and home-screen install all unlock the moment the site is served over TLS on its own domain — which the deployment does automatically. A native app for the same reach is a separate build, two store submissions, and a review cycle on every update.
